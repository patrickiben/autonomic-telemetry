# Current release scope

The current experience restores a personal experimental inferred-arousal estimate to the immersive signal canvas. Hume's reported HR and eligible Muse PRV are compared with a fixed initial personal reference, with a separate HR-only track and visible availability. The signed 0–100 scale centers on 50; weights, stability floors, and thresholds are declared heuristics. EEG remains separate context. Work supports continuous observation and an optional sustained-elevation cue; Rest adds paced breathing and a personal settling trend using the same estimate.

The separate Advanced Signal Lab preserves the normalized recording explorer, pattern-shift model, reference and novelty diagnostics, JSON export, and Health context. Additional [research lenses](RESEARCH_ENGINE.md) restore mathematical capabilities with audited definitions and input requirements. Its recording model is distinct from the new live estimate; input does not silently cross between them. The original user-provided prototype remains separate and untouched.

Muse provides raw EEG, optical, and motion previews as well as separately gated derived features. The live estimate is an inference from a cardiac pattern, not direct sympathetic activity, attention, meditation quality, or a health state. Source labels, reference progress, feature validity, and stale-data behavior remain visible. A functional score does not imply validated physiological accuracy; the display exposes its uncertainty and limitations.

Hume passed a bounded physical transport test on one Band V2: 84 validated nonzero responses over 90 seconds after acquisition, a longest gap of three seconds, and verified teardown. Its narrow start command renews every 20 seconds. One Athena Muse S passed a 40.3-second raw-stream test with eight EEG channels, four optical channels, and acceleration, without malformed packets, stale intervals, or adapter errors, followed by clean teardown. Both live sources also reached the canvas through the bridge in a mobile-sized desktop Chromium viewport; actual iPhone performance was not tested. These results do not establish physiological accuracy, indefinite operation, or universal firmware compatibility. See [Devices](DEVICES.md), [Methods](METHODS.md), and the [current validation notes](VALIDATION.md).
