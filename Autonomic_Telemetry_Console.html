Temporal texture

EXPLORATORY

Lag-1 heart-rate correlation and RMSSD dispersion in the latest contiguous clean window, up to 60 seconds. Neither establishes rigidity or predicts a transition.

Bring Hume data through Apple Health
  1. In Hume, open Me / Profile → Connected Apps → Apple Health. Enable the available categories you want to share, then sync.
  2. On iPhone, open Health → Summary → your picture / initials → Export All Health Data. Save the ZIP to Files.
  3. In Files, tap the ZIP to unpack it. Find apple_health_export/export.xml.
  4. Choose Open Health XML here, select export.xml, then choose the Hume source in the context panel.

Not every Hume metric is shared. If the expected reading is absent, use manual entry. On Android, manual entry is the supported path; this console does not import Google Fit.

Hume’s native export is listed as “Coming Soon” in its FAQ, checked October 22, 2026. This page does not claim a direct Hume Bluetooth or account connection. Official Hume guidance ↗

Browser, phone, and setup help

Use a Web Bluetooth capable browser such as Chrome or Edge on a supported desktop, or Chrome on Android. Open this console over HTTPS, including GitHub Pages, or on http://localhost. Bluetooth hardware and operating-system support still apply.

iPhone / iPad browsers and Safari / Firefox do not provide the standard Web Bluetooth path used here. Use a supported computer for Muse. The demo, file import, and daily context work on your phone.

If running locally, open Terminal in this repo folder:

python3 -m http.server 8090
# Open http://localhost:8090/

A connection is not a confirmed stream: the preview waits for a decoded sensor packet, then marks data stale after five seconds without one. If pairing fails, check Bluetooth, close other Muse apps, and reconnect.

From your Watch, through Health.

The shortest supported route is an Apple Health export. No account login is needed here.

  1. Let your Watch sync to Health on iPhone.
  2. Open Health → Summary → your picture / initials → Export All Health Data, then save the ZIP to Files.
  3. Tap the ZIP in Files to unpack it. Open apple_health_export/export.xml using the button below.
  4. If several sources appear, choose your Watch’s source in the context panel.

These are dated context summaries, not a live stream. Apple’s HRV quantity is SDNN; it does not fill the session’s RMSSD channel. A normal web page cannot directly read HealthKit, and this console does not connect to Apple Watch over Bluetooth.

You can use the file picker on your phone, or transfer the XML privately to your computer. Large Health exports can take time and memory to parse.
