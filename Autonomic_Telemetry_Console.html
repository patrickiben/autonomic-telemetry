Trend association

EXPLORATORY

Pearson correlation of aligned heart-rate and respiratory-rate samples. Shared trends can create associations. This does not measure respiratory sinus arrhythmia or causation.

Temporal texture

EXPLORATORY

Lag-1 heart-rate correlation and RMSSD dispersion in the latest contiguous clean window, up to 60 seconds. Neither establishes rigidity or predicts a transition.

State portrait

EXPLORATORY

Heart-rate z-score × RMSSD z-score relative to the reference. Two direct axes, no phenotype, embedding, or recovery claim.

Apple Watch & other wearables

Apple Health XML keeps the original source and date of each metric. Apple Watch HRV is SDNN; sparse summaries belong in context. Dense, timestamped features from any device can use the documented session CSV / JSON format.
